# Angular User Table App

This is an Angular 19 application that displays a list of users in a table with features like:
- Pagination
- Sorting (all columns)
- Search (by first name or last name)
- Routing to a detail page
- Viewing website links in a new tab
- Angular Material design

## 🔧 Technologies Used

- Angular 19
- Angular Material
- HTML, CSS
- ngx-pagination (for pagination)

---

## 📦 Installation

### 1. Clone the repository

git clone https://github.com/your-username/angular-user-table.git
cd angular-user-table


### 2. Install dependencies

npm install


▶️ Running the App

ng serve
